# Фото и видео проекта

Этот каталог предназначен для демонстрации работы NMEA Wi-Fi Bridge с Navionics Boating.

Планируемые файлы:

- `sonarchart-live.png` — глубина на карте и режим SonarChart Live;
- `navionics-connection.png` — подключение Lowrance Elite 4 HDI;
- `nmea-wifi-bridge-demo.mp4` — короткий ролик с демонстрацией работы, без звука.

**Пока файлы не загружены:** каталог подготовлен, но здесь находится только это описание.

Скриншоты приложения используются для иллюстрации совместимости и принципа работы любительского проекта. Navionics и SonarChart Live принадлежат их правообладателям, проект не связан с Garmin/Navionics.
