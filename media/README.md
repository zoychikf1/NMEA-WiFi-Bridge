# Фото и видео

Здесь хранятся иллюстрации и короткое видео, которые показывают, как NMEA Wi-Fi Bridge работает вместе с Navionics Boating.

Файлы:
- `sonarchart-live.png` — глубина на карте и включённый SonarChart Live;
- `navionics-connection.png` — подключение эхолота Lowrance Elite 4 HDI;
- `nmea-wifi-bridge-demo.mp4` — короткая демонстрация работы (без звука).

Скриншоты используются только для иллюстрации работы собственного устройства с совместимым приложением. Navionics и SonarChart Live принадлежат своим правообладателям; проект не связан с их разработчиками.
